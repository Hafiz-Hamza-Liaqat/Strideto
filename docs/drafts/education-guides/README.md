# Replacement education-guide drafts

These five JSON payloads are local, unpublished Blog drafts prepared for the
planned retirement of the standalone Schools & Colleges directory.

- They use only fields accepted by the existing Blog admin create contract.
- Every payload has `status: "draft"` and no publication date.
- Source-backed facts and official links are retained in each article's Sources
  section. The blog model has no separate sources field.
- Nothing in this directory has been sent to the CMS or production.

Import contract (when separately approved): authenticated staff `POST
/api/admin/blogs`, one payload at a time. Publishing is a separate action and
is intentionally out of scope.

The excluded Girls Cadet College Quetta record is not represented here.
